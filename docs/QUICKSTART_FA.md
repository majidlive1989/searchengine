# راهنمای اجرای Atlas نسخه ۰.۲

بعد از نصب می‌توانید منابع را خودتان در پنل اضافه کنید. در Source Studio نوع Direct JSON API را برای اتصال خودکار با API مجاز، یا Supplier website را برای ورود دستی نرخ‌های تأییدشده انتخاب کنید. کلید و مدل Gemini هم از بخش Settings داخل برنامه تنظیم می‌شود و نیازی به ارسال اطلاعات به توسعه‌دهنده نیست.

صرف واردکردن آدرس وب‌سایت به معنی جست‌وجوی خودکار آن سایت نیست؛ حالت وب‌سایت ورود دستی دارد. اتصال خودکار نیازمند API سازگار و تنظیم نگاشت اطلاعات، یا آداپتور اختصاصی است.

این بسته یک نسخه آزمایشی قابل اجرا از ایده شماست؛ شامل پنل کاربری، بک‌اند، دیتابیس، مدیریت درخواست، جست‌وجوی چندمنبعی، ساخت پیشنهاد قیمت و تأیید انسانی.

**منابع فعلی نمونه هستند و به تأمین‌کننده واقعی وصل نیستند.** قیمت‌ها و برنامه‌های سفر نمونه‌اند و امکان رزرو ندارند. اتصال واقعی نیازمند دسترسی مجاز آژانس و پیاده‌سازی اتصال هر تأمین‌کننده است.

## نصب روی ویندوز

Python 3.12 را نصب کنید. فایل ZIP را خارج کنید و PowerShell را داخل پوشه `travel-copilot` باز کنید:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe scripts\configure.py
.\.venv\Scripts\python.exe scripts\run.py
```

دستور configure یک رمز تصادفی می‌سازد و نمایش می‌دهد. رمز را نزد خود نگه دارید.

آدرس برنامه: **http://localhost:8000**

نام کاربری اولیه: `admin@agency.local`

رمز عبور: همان رمز تولیدشده هنگام configure.

برای اجراهای بعدی فقط دستور زیر لازم است:

```powershell
.\.venv\Scripts\python.exe scripts\run.py
```

رابط کامپایل‌شده داخل بسته است؛ برای اجرای اولیه به Node.js نیاز ندارید. بعد از تغییر کد فرانت‌اند، طبق README آن را دوباره build کنید.

## تست جریان کار

۱. در Source Studio روی Load demo sources بزنید تا چهار منبع نمونه ایجاد شود.

۲. یک New request بسازید و نام مشتری را وارد کنید.

۳. درخواست سفر را به فارسی یا انگلیسی بنویسید. در حالت آفلاین تاریخ را میلادی و به شکل `YYYY-MM-DD` وارد کنید. تبدیل تقویم شمسی و عبارت‌هایی مثل «هفته بعد» در حالت آفلاین انجام نمی‌شود.

۴. فرم مسیر، تاریخ، تعداد بزرگسال، اتاق و ستاره هتل را بررسی و Confirm details را بزنید.

۵. منابع را انتخاب و Search sources را اجرا کنید.

۶. یک پرواز و یک هتل انتخاب کنید، سود ثابت یا درصدی بگذارید و پیشنهاد را ذخیره کنید.

۷. پیشنهاد را تأیید و از گزینه Print / save PDF خروجی بگیرید. چاپ مشتری قیمت خالص و سود داخلی را نشان نمی‌دهد.

این نسخه فقط بزرگسال را پشتیبانی می‌کند. برای کودک، سن و قواعد قیمت‌گذاری باید در نسخه بعد توسعه داده شود. بیشتر بخش اصلی پنل فارسی/راست‌به‌چپ شده است؛ بعضی متن‌های مدیریتی انگلیسی‌اند.

## هوش مصنوعی و صدا

برای فعال‌سازی Gemini به Settings بروید، کلید و مدل مجاز را ذخیره و اتصال را تست کنید. تغییرات بدون ری‌استارت اعمال می‌شوند. بدون آن برنامه با استخراج محدود آفلاین کار می‌کند. اتصال Gemini بدون کلید شما به‌صورت واقعی آزمایش نشده است.

فایل صوتی پس از انتخاب به Gemini ارسال می‌شود و فایل خام در برنامه ذخیره نمی‌شود. متن پیاده‌شده را قبل از استخراج اطلاعات بررسی کنید. سیاست ارسال اطلاعات به ارائه‌دهنده باید مورد تأیید آژانس باشد.

## برای اتصال واقعی چه چیزی لازم است؟

- نام و دسترسی مجاز حداقل دو منبع پرواز و دو منبع هتل.
- اجرای آزمایش فنی OpenClaw یا Playwright روی همان پنل‌ها.
- تنظیم اتصال Direct JSON API در پنل؛ bridge فقط برای اتصال‌های سفارشی لازم است.
- برای پنل‌های بدون API از ثبت وب‌سایت و ورود دستی نرخ تأییدشده استفاده کنید.
- تأیید دستی تطابق قیمت و موجودی با پنل تأمین‌کننده.

رمز تأمین‌کننده را داخل چت یا فرم Source Studio ننویسید؛ فرم فقط شناسه حساب/پروفایل را نگه می‌دارد.

بکاپ و بازگردانی، Docker، تست‌ها، محدودیت‌ها و کارهای باقی‌مانده در فایل‌های پوشه docs توضیح داده شده‌اند. این نسخه روی اینترنت عمومی منتشر نشده و برای استقرار تولیدی نیازمند تکمیل اتصال‌ها و سخت‌سازی است.


اگر نسخه قبلی را اجرا کرده‌اید، قبل از ارتقا برنامه را متوقف و بکاپ بگیرید. پوشه data و فایل .env قبلی را به نسخه جدید منتقل کنید و configure.py را دوباره اجرا نکنید. فایل data/vault.key را نگه دارید؛ بازیابی اطلاعات رمزنگاری‌شده به آن نیاز دارد.
